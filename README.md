# kitchen-installation-ltd

Single-page website for **Kitchen Installation Team**, a kitchen remodeler in Bonnyrigg, Scotland.

Built with Vite + React 19 + TypeScript + Tailwind CSS 4.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # typecheck + production build
npm run preview  # serve the production build
```

## Features

- Full-width hero with WhatsApp quote CTA
- "Our work" photo carousel (auto-advancing, swipe support, prev/next controls)
- Three-step enquiry process
- Google rating + Maps listing link
- Enquiry form that opens WhatsApp with prefilled details
